# Akshat Shah Personal Website

A responsive, static personal portfolio built with HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` directly, or start a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a repository named `akshatrshah.github.io` on GitHub.
2. Initialize Git in this folder and push the files to the repository's `main` branch.
3. In repository settings, open **Pages**, choose **Deploy from a branch**, select `main`, and keep the folder at `/ (root)`.
4. The site will be available at `https://akshatrshah.github.io/`.
